# QueryNest

SQL-клиент на PyQt6 для работы с SQLite.

Сейчас программа умеет:
- открывать файл базы через диалог или меню;
- показывать список таблиц и первые 100 строк выбранной таблицы;
- выполнять произвольные SQL-запросы из редактора (по кнопке или Ctrl+Enter);
- выводить результат в таблицу или сообщать количество измененных строк;
- отображать ошибки выполнения в статус-баре и окне предупреждения.

Запуск через uv:

```bash
uv sync
uv run python main.py
```
