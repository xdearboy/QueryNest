Техническое задание для QueryNest.

Описание: Кроссплатформенный SQL клиент на PyQt6. Открывает файл SQLite, показывает таблицы и выполняет SQL-запросы.

Стек: PyQt6, SQLite3

Что умеет первая версия
- открытие SQLite-файла через диалог выбора файла;
- показывать список таблиц;
- по клику на таблицу показывать ее первые 100 строк;
- выполнять SQL-запрос из редактора;
- выводить результат в таблицу и показывать число строк;
- для запросов без результата, писать сколько строк изменено;
- показывать ошибки в статус баре;
- запоминать размер окна и последний открытый файл;

Что будет позже реализовано (если успею)
поддержка PostgreSQL и MySQL; подсветка синтаксиса; экспорт результатов в CSV; визуальный конструктор запросов

Примерный вид:

Меню: файл, открыть..., выход
слева QListWidget со списком таблиц
справа QSplitter: сверху QPlainTextEdit с кнопкой, снизу QTableWidget
внизу QStatusBar
ошибки будут показываться в QStatusBar и QMessageBox


Классы:

Database (database.py)
работает с SQLite файлом
- open(путь) открывает базу. если файл не найден, вызывает DatabaseError;
- close() закрывает соединение с базой;
- tables() возвращает список имен таблиц;
- columns(таблица) возвращает список названий столбцов таблицы;
- execute(запрос) выполняет SQL-запрос и возвращает названия столбцов, строки и количество измененных строк. при ошибке вызывает DatabaseError;
- preview(таблица) возвращает первые 100 строк таблицы.

MainWindow (main_window.py)
главное окно, наследуется от QMainWindow, создает интерфейс и работает с Database
- open_file() показывает диалог выбора файла и открывает базу;
- load_tables() заполняет список таблиц слева;
- on_table_clicked() показывает первые 100 строк выбранной таблицы;
- run_query() выполняет запрос из редактора и выводит результат;
- show_result(столбцы, строки) заполняет QTableWidget;
- show_error(текст) показывает ошибку в статус баре и в QMessageBox;
- closeEvent() сохраняет размер окна и последний файл через QSettings.

main.py
создает QApplication и MainWindow, запускает программу.
