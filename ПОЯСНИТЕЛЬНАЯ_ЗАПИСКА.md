# Пояснительная записка QueryNest

## Введение

QueryNest — кроссплатформенный SQL-клиент для работы с SQLite базами данных. Приложение предоставляет графический интерфейс для открытия баз, просмотра таблиц и выполнения SQL-запросов без необходимости использования командной строки.

### Цель проекта

Создать удобный инструмент для работы с SQLite базами, который позволит:
- Быстро открывать и исследовать базы данных
- Просматривать содержимое таблиц
- Выполнять произвольные SQL-запросы
- Видеть результаты в удобном виде

## Описание функциональности

### Основные возможности

1. **Открытие SQLite-файла**
   - Диалог выбора файла
   - Поддержка расширений .db, .sqlite, .sqlite3
   - Проверка корректности файла базы

2. **Просмотр таблиц**
   - Список всех таблиц в левой панели
   - Клик на таблицу показывает первые 100 строк
   - Автоматическое отображение названий столбцов

3. **Выполнение SQL-запросов**
   - Редактор SQL-кода в центральной части
   - Кнопка выполнить (или горячая клавиша Ctrl+Enter)
   - Вывод результатов в таблицу
   - Поддержка SELECT, INSERT, UPDATE, DELETE

4. **Обработка ошибок**
   - Отображение ошибок в статус-баре
   - Всплывающее окно с описанием проблемы
   - Корректное восстановление после ошибок

### Интерфейс

Приложение имеет простой и интуитивный интерфейс:
- **Левая панель**: кнопка открытия базы и список таблиц
- **Правая панель (сверху)**: редактор SQL-запросов с кнопкой выполнить
- **Правая панель (снизу)**: таблица результатов
- **Меню**: "Файл" (Открыть базу, Выход)
- **Статус-бар**: информация о результатах и ошибках

### Компоненты

#### Database (database.py)

Класс для работы с SQLite базой:

```python
class Database:
    def open(path)          # Открыть базу
    def close()             # Закрыть соединение
    def tables()            # Получить список таблиц
    def columns(table)      # Получить столбцы таблицы
    def execute(sql)        # Выполнить SQL-запрос
    def preview(table)      # Получить первые 100 строк
```

**Отвечает за:**
- Подключение к SQLite базе
- Валидацию файла базы
- Выполнение запросов
- Обработку ошибок (DatabaseError)

#### MainWindow (main_window.py)

Главное окно приложения:

```python
class MainWindow(QMainWindow):
    def setup_menu()        # Создать меню
    def setup_ui()          # Создать интерфейс
    def open_file()         # Диалог открытия файла
    def load_tables()       # Загрузить таблицы
    def on_table_clicked()  # Показать таблицу
    def run_query()         # Выполнить запрос
    def show_result()       # Вывести результаты
    def show_error()        # Показать ошибку
```

**Отвечает за:**
- Создание интерфейса
- Обработку действий пользователя
- Отображение результатов
- Управление ошибками

## Инструкция по запуску

### Требования

- Python 3.12+
- uv (менеджер зависимостей)

### Установка и запуск

```bash
# Установить зависимости
uv sync

# Запустить приложение
uv run python main.py
```

### Использование

1. Нажать кнопку "Открыть базу" или Ctrl+O
2. Выбрать SQLite-файл (.db, .sqlite, .sqlite3)
3. В левой панели появится список таблиц
4. Кликнуть на таблицу для просмотра первых 100 строк
5. В редактор справа вписать SQL-запрос
6. Нажать "Выполнить" или Ctrl+Enter
7. Результаты появятся в таблице снизу

## Примеры использования

### Пример 1: Просмотр таблицы

```
1. Открыть базу demo.sqlite
2. Кликнуть на "students" в списке слева
3. Увидеть: id, name, age, city
4. Таблица покажет: Аня, Илья, Маша, Тимур
```

### Пример 2: SQL-запрос

```sql
SELECT name, age FROM students WHERE age > 15
```

Результат: две строки (Илья, Тимур)

### Пример 3: Изменение данных

```sql
UPDATE students SET age = 16 WHERE name = 'Аня'
```

Статус-бар покажет: "Запрос выполнен. Изменено строк: 1"
